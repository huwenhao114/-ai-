# 学习计划编写 Skill

## 用途

帮助大学生为某门课程或某个阶段制定结构清晰、可执行的学习计划。本 Skill 定义学习计划的结构规范、内容要点与质量标准，供 Agent 在调用 `create_study_plan` 工具前后参考。

## 何时使用

- 用户要求「帮我制定 XX 课程的学习计划」
- 用户提到「我要复习 XX」「准备考试」「这周怎么学」
- 用户希望获得学习安排、时间规划建议

## 计划结构规范

一份合格的学习计划应包含以下部分（按顺序）：

1. **标题**：`# 📚 {课程名} 学习计划`
2. **元信息**：生成时间、计划周期（周数）、学习重点
3. **学习目标**：1-2 句话说明本计划要达成的目标
4. **分周安排**：每周包含
   - 本周主题（结合课程大纲）
   - 本周任务清单（阅读、笔记、练习、回顾）
   - 学习提示
5. **复习与检测**：阶段性回顾方法
6. **免责声明**：提示结合自身情况调整

## 内容要点

### 分周主题生成规则
- 根据课程名称匹配预设主题（如数据结构→线性表/树/图/排序）
- 匹配不到时使用「第 N 章核心知识点」通用模板
- 周数应在 1～16 之间，超出则截断

### 任务设计原则
- 每周任务时间总量控制在 5～6 小时（符合大学生课余学习节奏）
- 任务类型覆盖：输入（阅读/听课）、整理（笔记）、输出（练习）、回顾（错题）
- 使用 checkbox 列表 `- [ ]` 便于打卡

### 学习提示编写
- 针对学习重点给出具体建议
- 提醒及时答疑、保持节奏
- 鼓励性语言，避免说教

## 质量检查清单

生成计划后，Agent 应自检：
- [ ] 是否包含完整的 6 个结构部分
- [ ] 每周任务是否有 4 类（阅读、笔记、练习、回顾）
- [ ] 周数是否与用户要求一致
- [ ] 是否提醒用户结合自身情况调整
- [ ] 是否保存到 output 目录

## 示例调用

用户：「帮我制定数据结构的 4 周学习计划，重点是图和排序」

Agent 行为：
1. 调用 `create_study_plan(course_name="数据结构与算法", weeks=4, focus="图和排序")`
2. 工具返回文件路径后，向用户说明：
   - 计划已生成，覆盖 4 周
   - 重点章节已标注
   - 文件保存在 output 目录
3. 可主动询问是否需要调整周数或重点

## 注意事项

- 不要凭空编造课程大纲内容，主题建议来自预设或通用模板
- 计划仅供参考，必须提示用户结合自身实际调整
- 不涉及具体考试题目、答案等违规内容
