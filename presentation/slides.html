一、项目介绍

「校园学习助手」是一个面向在校大学生的智能体应用。

学生用自然语言提问，智能体自动调用工具完成任务，并把学习计划、成绩报告等产出物保存为文件。

解决的痛点

  • 课程信息分散在不同平台，查课不方便
  • 多门课作业截止日期记不住
  • 想复习但不知道怎么安排学习计划
  • 拿到成绩不知道薄弱环节在哪

选题方向

课程助教（属于期末要求第三节推荐选题列表）

二、技术栈

类别选型说明

满足路径 A 最低配置全部 7 项 + 长期记忆（AGENTS.md）加分项。

三、系统架构

用户 → Streamlit 界面 → LangChain Agent → 工具 / 模型 / Skill
                                          ↓
                                    output/ 产出文件

模块说明

  • app.py：Streamlit 主界面，聊天、工具调用展示、会话管理
  • agent.py：Agent 核心，配置阿里百炼模型、绑定工具、多轮对话
  • tools/：4 个自定义工具
  • skills/study-plan-writer/SKILL.md：学习计划编写规范
  • data/courses.json：示例课程、成绩、作业数据
  • AGENTS.md：长期记忆

四、自定义工具（4 个）

1. query_courses — 课程查询

按课程名 / 教师 / 编号搜索，返回课程信息、上课时间、教学大纲。

query_courses(keyword="开源AI")

2. get_upcoming_assignments — 作业提醒

查询未来 N 天内即将截止的作业，显示剩余天数。

get_upcoming_assignments(days=30)

3. create_study_plan — 学习计划生成

根据课程、周数、重点生成学习计划，写入 output 目录。

create_study_plan("数据结构", weeks=4, focus="图")

4. analyze_grades — 成绩分析

分析成绩，识别薄弱课程，给出建议，生成分析报告。

analyze_grades(student_id="20240001")

五、Skill：学习计划编写规范

文件位置：skills/study-plan-writer/SKILL.md

Skill 内容

  • 定义学习计划的结构规范（6 个必备部分：标题、元信息、学习目标、分周安排、复习检测、免责声明）
  • 规范每周任务设计（阅读、笔记、练习、回顾四类）
  • 提供质量检查清单
  • 指导 Agent 如何与用户交互

Skill 与系统提示词的区别

系统提示词管全局行为（角色、边界）；Skill 是可复用的领域知识包，独立维护，管具体任务的专业规范。

七、使用阿里百炼的方法

步骤 1：获取 API Key

  1. 登录 https://bailian.console.aliyun.com/
  2. 左侧菜单「模型服务」→「API-KEY 管理」
  3. 点击「创建新的 API-KEY」，复制生成的 Key

步骤 2：配置到项目

copy .env.example .env

编辑 .env 文件：

DASHSCOPE_API_KEY=sk-你的真实Key
LLM_MODEL=qwen-plus
OPENAI_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1

步骤 3：启动

streamlit run app.py

九、思政与合规

  • 所有课程、成绩、作业均为虚构示例数据，不涉及真实学生信息
  • API Key 通过 .env 管理，不进 Git 仓库
  • 涉及成绩、制度时提示「以官方为准」
  • 不代写作业、不提供考试答案

十、不足与后续改进

  • 当前不足：课程数据为本地 JSON，未对接真实教务 API；未实现流式输出
